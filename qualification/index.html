    Occupational Certificate: Software Developer

    • SAQA ID: 118707
    • Curriculum Code: 251201-005-00-00
    • NQF Level: 5
    • Total Credits: 220 (~2,200 Notional Hours)

    Tripartite Curriculum Structure

    1. Knowledge Modules (66 Credits)

    • KM-01: Computers and Computing Systems (12 Credits)
    • KM-02: Information Visualisation Software (8 Credits)
    • KM-03: Web Scraping Data Pipelines (8 Credits)
    • KM-04 to KM-05: Logic, Calculations, & Computing Theory (4 Credits)
    • KM-06: Software Development with HTML5 & Open-Source Frameworks (16 Credits)
    • KM-07: UML Systems Modelling (4 Credits)
    • KM-08: Data Querying & MVC Architecture (6 Credits)
    • KM-09: SDLC, Algorithms & Security (3 Credits)
    • KM-10 to KM-12: Governance, 4IR & Design Thinking (5 Credits)

    2. Practical Modules (89 Credits)

    • PM-01 to PM-05: Analytics, Dashboards & Data Manipulation (15 Credits)
    • PM-06 to PM-07: Applied Logic & Software Toolkits (6 Credits)
    • PM-08: HTML5 & Modern Web Development (16 Credits)
    • PM-09: Web, Desktop GUI, & Mobile Applications (8 Credits)
    • PM-10: Cloud Automation Solutions (8 Credits)
    • PM-11: Software Development with Python (12 Credits)
    • PM-12: Full SDLC Agile Project Implementation (16 Credits)
    • PM-13 to PM-14: Design Thinking & Teamwork Ethics (8 Credits)

    3. Work Experience Modules (65 Credits)

    • WE-01: Technical Requirement Analysis & Refinement (15 Credits)
    • WE-02: Systems Process Modelling (15 Credits)
    • WE-03: Production Software Programming (25 Credits)
    • WE-04: Capstone Project Execution (10 Credits)
